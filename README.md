CÁCH CHẠY PROJECT:

(Front-end)
B1: Mở terminal của folder project.
B2: Nhập "cd frontend ; npm install".
B3: Nhập "cd frontend ; npm run dev".
B4: Bấm vào link hiển thị sau khi chạy xong (localhost:/...).

(Back-end)
B1: Mở terminal của folder project.
B2: Nhập "cd backend ; npm install".
B3: Nhập "cd backend ; npm run dev".

QUY LUẬT COMMIT:

- KHI PULL PROJECT VỀ, TRƯỚC KHI BẮT ĐẦU CODE PHẢI "git checkout <tên nhánh của mình>"
- KHI CODE XONG:
	B1: "git add ."
	B2: "git commit -m 'mô tả ngắn những gì đã làm'
	B3: "git checkout frontend(hoặc backend)"
	B4: "git merge <tên nhánh của mình>"
	B5: "git push"
	B6: "git checkout <tên nhánh của mình>"
